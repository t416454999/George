🌌 关于极光引擎

什么是极光引擎？

极光引擎 是一个专注于人工智能领域的自动资讯聚合平台。如同夜空中变幻莫测的极光，AI技术日新月异——我们致力于捕捉每一道闪耀的技术光芒，将它们汇聚于此。

每天自动从多个国内优质AI媒体采集最新资讯，无需翻墙即可浏览全球AI前沿动态。

核心功能

  • 🤖 每日自动更新：通过GitHub Actions每天自动采集最新AI资讯
  • 📡 多源聚合：整合机器之心、量子位、36氪等多个AI媒体
  • 🏷️ 分类筛选：按大模型、AI应用、AI绘画等分类浏览
  • 🔍 全文搜索：快速找到感兴趣的AI话题
  • 📱 响应式设计：完美适配电脑、平板、手机
  • ⚡ 免费部署：基于GitHub Pages，完全免费，国内可直连

技术架构

纯静态站点 + Python自动采集脚本 + GitHub Actions定时任务 → GitHub Pages托管

无需服务器、无需数据库、无需后端，极致轻量，永久免费。
