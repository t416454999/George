## P0：立即处理

### BUG-P0-01：公网暴露 Git 元数据

- 状态：✅ 已修复并上线。`/.git/HEAD`、`/.git/config` 已返回 404；保留 `/.well-known/`。
- 复现：`/.git/HEAD`、`/.git/config` 返回 HTTP 200。
- 根因：Nginx 站点配置只使用 `try_files`，没有禁止隐藏文件；网站根目录同时是完整 Git 工作区。
- 影响：外部人员可还原仓库结构和历史；未来误提交过的密钥或内部信息即使删除，也可能被恢复。
- 修复：Nginx 禁止 dotfiles，保留必要的 ACME 验证例外；执行配置检查和 reload 后验证返回 403/404。
- 验收：`/.git/HEAD`、`/.git/config`、`/.env`、任意隐藏文件均不可访问。

### BUG-P0-02：专题详情不能刷新、分享或直达

- 状态：✅ 已修复并上线。新旧详情地址均经真实 Chrome 直达和刷新验证。
- 复现：进入情感详情 `#详情/1832866913` 后刷新，地址跳回首页，标题消失。
- 根因一：路由直接比较 `location.hash.slice(1)`，没有先执行 `decodeURIComponent`。
- 根因二：刷新初始化只加载 AI 数据库和首页精选，专题文章只存在运行时专题缓存；即使解码 hash 也找不到专题文章。
- 影响：国际形势、世界杯、人文艺术、情感等详情无法可靠分享；刷新和浏览器恢复失败。
- 修复：详情路由携带栏目并按栏目加载对应 JSON，或生成全站详情索引；同时安全解码 hash。
- 验收：复制专题详情地址到无痕窗口能打开；刷新后仍停留在同一文章；错误 ID 显示明确 404 状态而不是静默回首页。
- 涉及：`极光脚本.js` 路由初始化与详情查找逻辑。

## P1：高优先级

### BUG-P1-01：外部内容未转义，存在页面内容注入风险

- 状态：✅ 已修复并上线。外部文本改为安全 DOM/转义渲染，外链限制为 HTTP(S)。
- 范围：首页普通卡片、金融列表、行业热议、GitHub 工具、平台热点、搜索结果和无结果提示。
- 根因：外部标题、摘要、来源、链接和搜索词直接拼接进 `innerHTML`。
- 影响：恶意或异常数据可能插入 HTML、伪造链接、破坏布局，严重时执行脚本。
- 修复：文本统一使用 `textContent` 或可信转义函数；链接只允许 `http/https`；禁止在模板中插入未经处理的外部字段。
- 验收：用包含 `<img onerror=...>`、引号和脚本标签的测试数据，不得产生 DOM 节点或执行代码。

### BUG-P1-02：GitHub 工具排行自动更新每日失败

- 状态：✅ 已修复。Actions 已固定完整 SHA，工作流 YAML 验证通过。
- 证据：最近运行 `29245637428` 失败；仓库要求 Actions 固定完整 SHA，但工作流仍使用 `actions/checkout@v4`、`setup-python@v5`。
- 影响：GitHub 工具排行停止更新，失败可能长期无人发现。
- 修复：按其他工作流的方式固定到已验证完整 SHA，手动触发并检查产物提交。

### BUG-P1-03：所有静态资源无有效缓存

- 状态：✅ 已修复并上线。HTML 60 秒、JSON 5 分钟、CSS/JS/图片 30 天；前端移除 `Date.now()`。
- 证据：HTML、CSS、JS、JSON、WebP 均返回 `no-cache, must-revalidate`；JSON 请求还附加 `Date.now()`。
- 影响：每次访问和切换都重新验证资源，是图片慢和重复流量的直接原因。
- 修复：HTML短缓存/不缓存；动态 JSON 短 TTL；带版本的 CSS/JS 与 `assets/` 设置 7–30 天 `public, immutable`；移除 `Date.now()`，改用构建版本或数据更新时间。
- 验收：第二次访问静态图片和版本化 CSS/JS 命中内存/磁盘缓存，栏目 JSON按设计的短 TTL 更新。

### BUG-P1-04：国际形势栏目造成移动端横向溢出
